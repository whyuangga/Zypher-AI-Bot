# Font

`GeneralSans-Regular.woff2` dan `GeneralSans-Medium.woff2` — **General Sans**
oleh Indian Type Foundry, diambil dari [Fontshare](https://www.fontshare.com/fonts/general-sans).

Dilisensikan lewat **ITF Free Font License**: gratis untuk proyek pribadi maupun komersial,
termasuk *self-hosting*. File disimpan di repo supaya dashboard tidak perlu mengambil font
dari CDN (panel hosting bisa tanpa akses internet keluar).

Dipakai lewat `@font-face` di `src/web/ui/theme.ts` dan disajikan oleh rute `/fonts/...`
di `src/web/server.ts`.
